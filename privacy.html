Privacy Policy

Last updated: 2026-10-06

Ray Data Search ("the App") is a personal-use application that searches and retrieves publicly available data via TikTok's API for the developer's own research purposes.

  1. What we collect: The App only retrieves publicly available TikTok data returned by TikTok's API in response to search queries (e.g. public video metadata, hashtag or trend information). It does not collect personal data about any individual beyond what is already public on TikTok.
  2. What we don't do: The App does not collect login credentials, private messages, or any non-public data. It does not sell, share, or transfer any data to third parties.
  3. Storage: Any data retrieved is stored locally by the developer for personal analysis only and is not published, redistributed, or made available to any other party.
  4. Retention: Data is retained only as long as needed for the developer's own research and may be deleted at any time.
  5. Third-party terms: Use of TikTok's API is additionally governed by TikTok's own Privacy Policy and Developer Terms.
  6. Contact: Questions about this policy can be directed to the developer via the GitHub repository hosting this page.
